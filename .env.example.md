# Environment Variables Example

Never commit real secrets. Configure values only in Vercel, Supabase, or the provider dashboard. The repository documents names and boundaries, never secret values.

## Canonical application and database

```bash
NEXT_PUBLIC_APP_URL=
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

```

## Universal GPT production control plane

```bash
# Stable MCP endpoint used by every authorized GPT and factory project.
AUTO_BUILDER_2_MCP_URL=https://auto-builder-strategic-minds-advisory.vercel.app/api/auto-builder-2/mcp

# Configure one shared server-only authorization value in both control-plane projects.
# The lookup order allows existing deployments to reuse their current bridge credential.
AUTO_BUILDER_OPERATOR_TOKEN=
AGENT_OPERATOR_TOKEN=
BRIDGE_SECRET=
BRIDGE_API_KEY=
ADMIN_API_TOKEN=
```

## Native Xtreme AI Builder adapter


## Security boundaries

- `SUPABASE_SERVICE_ROLE_KEY`, `GITHUB_TOKEN`, `VERCEL_TOKEN`, `BROWSER_WORKER_SECRET`, `CRON_SECRET`, bridge credentials, and provider tokens are server-only.
- GPTs and agents call the authenticated Universal GPT control plane. They never receive raw provider credentials.
- New generated repositories are private and restricted to approved Strategic Minds owners.
- New projects automatically create or reuse their GitHub repository and connected Vercel project.
- Preview deployments are validation infrastructure. The final destination is production after required build, security, BrowserWorker, visual, functional, and smoke-test gates pass.
- A critical production smoke failure triggers rollback, repair, and redeployment.
- Billing, purchases, customer messaging, secret disclosure, and destructive deletion remain separately governed.
