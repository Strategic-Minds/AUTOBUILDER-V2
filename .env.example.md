## Security boundaries

- `SUPABASE_SERVICE_ROLE_KEY`, `GITHUB_TOKEN`, `VERCEL_TOKEN`, `BROWSER_WORKER_SECRET`, `CRON_SECRET`, shared control-plane credentials, `PROOF_OPERATOR_TOKEN`, and provider tokens are server-only.
- GPTs and agents call the authenticated Universal GPT control plane. They never receive raw provider credentials.
- New generated repositories are private and restricted to approved Strategic Minds owners.
- Every new project creates or reuses its repository and Vercel project before generation begins.
- BrowserWorker never receives the Supabase service-role credential.
- Preview deployments are internal validation stages and cannot unlock a project.
- Production promotion occurs only after required release gates pass, and production smoke failure invokes the recorded rollback baseline.
- DNS changes, billing, customer messaging, secret disclosure, destructive deletion, and repository retirement remain separate protected actions.
